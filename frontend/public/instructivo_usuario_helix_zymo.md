# Instructivo de usuario - Helix Zymo

## Objetivo
Usar Helix Zymo para registrar actividades, hacer seguimiento Scrum/Gantt, cargar evidencias, controlar costos, enviar alertas y generar reportes de estado.

## 1. Panel de control
- Revisa avance, riesgos, carga de trabajo, flujo por subproyecto y analisis IA.
- Usa el selector de subproyecto para ver avances especificos.
- Prioriza actividades vencidas, bloqueadas o de alta prioridad con bajo avance.

## 2. Crear o editar actividades
1. Entra a Config o Scrum.
2. Selecciona Nueva actividad o Editar datos.
3. Completa responsable, subproyecto, fechas, estado, prioridad y avance.
4. Registra costos de inversion, optimizacion y ejecucion.
5. Guarda la actividad.

## 3. Evidencias y comentarios
- En Scrum, abre Comentarios/Evidencias en una actividad.
- Usa Adjuntar evidencia para cargar soportes.
- Agrega comentarios con avances, acuerdos, bloqueos o decisiones.
- Para observaciones recibidas por WhatsApp, usa Obs. WhatsApp.

## 4. Alertas
- Usa Correo o WA en los registros de actividad.
- Las alertas incluyen responsable, motivo, avance, fecha e impacto cliente.
- Revisa alertas automaticas para vencimientos, bloqueos o actualizaciones relevantes.

## 5. Reportes
- En Estados, consulta el informe gerencial.
- Puedes copiar el estado, enviar flujograma por correo o preparar envio por WhatsApp.
- El informe incluye estado, decision gerencial, riesgos, ROI, costos y acciones.

## 6. Instructivos
- En Soporte, descarga esta guia o el instructivo gerencial.
- Tambien puedes cargar instructivos propios en PDF, Word, TXT o Markdown.

## Buenas practicas
- Actualiza avance al cierre de cada jornada.
- Carga evidencia en tareas terminadas o en revision.
- Registra bloqueos apenas aparezcan.
- Mantiene costos actualizados para que ROI y ejecucion sean confiables.
