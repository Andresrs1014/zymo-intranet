# Flujo Añadir Tarea (Personal, ya realizada)

Herramienta utilizada por todo `ROL` establecido en la herramienta.
Una vez configurada y confirmada este funcionando y sea visible para el colaborador la herramienta, este esta en la capacidad de acceder a las herramientas de `zymointranet.com` ese sera el portal para registrar una tarea:

`Mis  herramientas -> Nueva tarea -> Diligenciamiento de cada campo -> Subir tarea`

*Cada flecha representa avance en el cargue de tareas*

Es importante recalcar que en el apartado de `Diligenciamiento de cada campo` debe ingresar la fecha (menor a ese día) y la hora de realización. Este para `Estados` debe aplicar únicamente en finalizado, para tareas bloqueadas.

# Flujo agendar tarea (Tareas a realizar - equipo completo)

Herramienta utilizada por todo `ROL` establecido en la herramienta.
Una vez configurada y confirmada este funcionando y sea visible para el colaborador la herramienta, este esta en la capacidad de acceder a las herramientas de `zymointranet.com` ese sera el portal para asignar una tarea: 

`Mis herramientas -> Asignar tarea -> Escoge persona para asignar -> Diligenciamiento de los demas campos -> Asignar tarea`

*Cada flecha representa avance en la asignación de tareas*

Es importante para este flujo asignar fecha de asignación y debe asignar el tiempo que puede llegar a demorarse esa tarea. Esto para que la otra persona pueda ver de que se trata.

También en los `Estados` de esta asignación debe encontrarse, Completada, En progreso, Sin iniciar (Este debe ser el default dado el caso de que no se elija nada o efectivamente este sin iniciar) y bloqueada

#### Flujo de persona asignada

`Mis herramientas -> Revisar tareas -> Aceptar tarea`

Al aceptar una tarea debe poder editarla, en sus estados y debe de poder registrar el tiempo que se demoro, el sistema hará una comparativa del tiempo estimado que debía demorarse a lo que realmente se demoro (Esto no es nada malo ni es un indicador negativo) En la descripción de la tarea podrá verse este detalle, que únicamente mostrara cuanto se demoro, cuanto tiempo se le había asignado.

# Flujo de Agendar una tarea (Bloqueo de Agenda - Todo el equipo)

Herramienta utilizada por todo `ROL` establecido en la herramienta.
Una vez configurada y confirmada este funcionando y sea visible para el colaborador la herramienta, este esta en la capacidad de acceder a las herramientas de `zymointranet.com` ese sera el portal para agendar una tarea:

`Mis herramientas -> Agendar tarea (Calendario) -> Escoger Fecha -> Participantes de la agenda -> Agendar una tarea, reunión, socialización`

El agendamiento de una tarea, debe corresponder a una actividad de reunión de equipo (Personas agendadas) o reunión general del equipo con otras áreas, debe ser diligenciada la hora a la que se inicia y cuanto durara, este debe mostrar que agenda tienen para ese día las personas citadas, Si ya esta citado, esto no debe impedir que agende la reunión. Es importante saber si se va hacer en que sede y si es virtual o no. 

#### Persona agendada 

`Mis herramientas -> Calendario -> Descripción de la agenda -> Aceptar Si o No`

Esto con el fin de que se confirme la asistencia también para control de las tareas.
